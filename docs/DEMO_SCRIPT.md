# Three-Minute Demo Script

## 0:00–0:25 — Problem

“Researchers often start with an interest, not a search query. Research Compass makes the exploration process visible so the system helps narrow the question instead of pretending to decide the research direction.”

## 0:25–1:05 — Intent Studio

Load the labeled Golden Case snapshot. Point out the NN → GP relationship, control-theory domain, editable intent and source label. Say explicitly that this is a historical Qwen/OpenAlex snapshot, not a new live call. Show that clarification can be skipped.

## 1:05–1:55 — Path Explorer

Compare the path cards and English queries. Select a path and show the source-linked OpenAlex title, abstract, paper ID, rank and relevance explanation. Explain that real retrieval occurs only after path selection and cached paths can be revisited.

## 1:55–2:35 — Evidence & Next Steps

Show the separation between relevance, abstract eligibility and claim support. Candidate questions are hypotheses to verify. Point to an excerpt and its paper link; note that abstracts are not full-text verification. If evidence is insufficient, the product reports that limitation.

## 2:35–3:00 — Evaluation and honest limits

Present the one-case V0/V1 metrics and explain the different branch sets. The results are preliminary and say nothing about Qwen uplift. Mention that public Qwen is disabled until real persistent-budget and deployment checks pass.
