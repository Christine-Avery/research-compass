# 简历项目：Research Compass

面向科研新手的探索式学术搜索产品，将模糊研究兴趣转化为结构化意图、可选研究路径、OpenAlex 文献证据和下一步检索。负责产品定义、MVP 交付、评测设计与发布安全治理；线上默认使用 Rules V1，实时 Qwen 保持关闭。

## 三项核心贡献

1. **用户需求、MVP 与 Web 产品交付：** 定义并交付三页核心旅程（意图确认 → 路径选择与真实文献检索 → 证据边界与下一步检索），复用 OpenAlex/PyAlex 建立可追溯的摘要、来源链接和论文 ID 展示。
2. **AI 搜索评测、Bad Case 归因与检索优化：** 围绕同一冻结 Golden Case 和 35 条分支级人工论文判断迭代 Rules V1，P@5 从 0.05 提升至 0.80、nDCG@5 从 0.1077 提升至 0.8210；明确标注这是单案例规则迭代，不代表跨查询泛化或 Qwen 增益。
3. **LLM 增量价值、技术选型与成本安全治理：** 在 16 条新建合成需求中完成 Rules V1 / Qwen V2 配对检索，11 条完整配对的机器辅助初评 P@5 为 0.636→0.836、nDCG@5 为 0.717→0.905；发现 Qwen 结构化方向字段保留为 0/8、端到端中位时延约 19.8 秒，建议 Rules-first + Selective LLM。独立复算与一致性审计已通过，标签尚待人工抽样验证；另设计 Redis 预算门、并发保护和 fail-closed 降级，线上 Qwen 仍关闭。

## 岗位适配重点

- **AI 应用 PM：** 意图编辑、证据透明、失败降级与研究假设边界。
- **AI Search PM：** 查询规划、分支探索、真实检索、指标评估与 Bad Case 归因。
- **AI 平台 PM：** 模型/检索分工、调用成本、并发安全和可追溯实验记录。
- **通用 AI PM：** 需求定义、范围取舍、实验口径、协同交付与风险披露。

## 面试中的边界说明

实验一是历史 Golden Case 上的 Rules V0→V1 迭代；实验二是另一组 16 条合成需求上的 Rules V1 vs Qwen V2 对照。两组数据集和问题不同，不能合并或混作模型增益。实验二属于 exploratory paired evaluation，119 条相关性记录为 machine-assisted provisional，尚未完成人工裁定；只有 11/16 完整配对，S4 无完整配对，路径选择器还有实现偏差。结论用于支持继续评估选择性调用，不证明统计显著提升或总体用户价值。公开 Qwen 未启用。Codex 协助代码和文档产出；本人负责产品范围、决策、评测约束审查和交付验收，不将模型辅助开发表述为独立手工完成所有代码。
